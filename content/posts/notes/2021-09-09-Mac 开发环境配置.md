新 Mac 或重装后，我固定走一条路径：克隆 [dotfiles](https://github.com/zhijunio/dotfiles)，执行 `./bootstrap.sh`。Homebrew 负责 GUI 和通用 CLI；**mise** 负责语言运行时版本；仓库里的文件通过 **symlink** 挂到 `$HOME`。

<!--more-->

## 环境参考

- macOS 26.x，Apple Silicon
- Shell：Homebrew `zsh` + Oh My Zsh + Starship
- 容器：OrbStack（`Brewfile` cask）
- 运行时：mise（配置在 `dotfiles/mise/config.toml`）

## 分工

| 层级 | 负责什么 |
| --- | --- |
| `bootstrap.sh` | Homebrew bundle、mise 安装与 `mise install`、symlink、可选 Bitwarden 恢复 |
| `Brewfile` | git、gh、Ghostty、Cursor、OrbStack 等（**不含** Node/Python/pnpm） |
| `dotfiles/mise/config.toml` | Java、Maven、Gradle、Spring Boot CLI、Node、pnpm、Python、pipx 等 |
| `dotfiles/.zshrc` 等 | Shell、别名、Git、Maven settings |

## 安装

### 1. Command Line Tools

```bash
xcode-select --install
git --version
```

### 2. 引导

```bash
git clone https://github.com/zhijunio/dotfiles.git ~/github/dotfiles
cd ~/github/dotfiles
./bootstrap.sh
```

脚本会：安装/使用 Homebrew 并按 `Brewfile` **补缺且不升级**已有包；安装 mise 并 `mise install`；把 `dotfiles/mise/config.toml` 链到 `~/.config/mise/config.toml`；为 `.zshrc`、`.gitconfig`、`.m2/settings.xml` 等建 symlink（已有且非指向仓库则跳过）；按需 clone Oh My Zsh。

Bitwarden CLI 由 mise 提供，脚本会**尝试**从 Secure Note 恢复 SSH、rclone、`.env`；失败只告警。本地已有 SSH 私钥不会覆盖。

工作 Git 身份（可选）：

```bash
export WORK_NAME="Your Name"
export WORK_EMAIL="you@company.example"
./bootstrap.sh
```

个人身份在 `dotfiles/.gitconfig`；`~/work/` 下仓库加载本机 `~/.gitconfig.work`（不进 Git）。

### 3. 系统偏好（可选）

```bash
./setup_macos.sh
```

设置时区、KeyRepeat、Dock/Finder 等，需 `sudo`。

## mise 全局版本

`dotfiles/mise/config.toml` 要点：

- **Java**：列表第一项为默认（当前为 Oracle GraalVM 25）；另装 GraalVM 21/17、Temurin 27、Zulu 8。
- **Node / pnpm**：26.9.0、12.17.0；`pnpm = "npm:pnpm"`（本机 aqua 包解压失败时的 alias）。
- **构建**：Maven 3.10.0、Gradle `latest`、Spring Boot CLI 4.1.0（社区 asdf 插件，commit 已 pin）。
- **其它**：Python 3.13.16、pipx、Bitwarden CLI、Pi 等。

项目根目录可写 `mise.toml` 覆盖，例如不同仓库 pin 不同 pnpm 主版本。

```bash
mise ls --current
mise install
mise exec npm:pnpm@10.34.9 -- pnpm --version
```

当前 shell 临时换 Java（`~/.aliases`）：`j8` / `j17` / `j21` / `j25` / `j27` → `mise shell java@…`。

改全局版本：编辑 `dotfiles/mise/config.toml` → `mise install` → 提交 dotfiles。

## Homebrew 清单

除上表外的典型项：`starship`、`docker-compose`、`ffmpeg-full`、`pandoc`、`cursor`、`codex`、`claude-code`、`cc-switch`、`ghostty`、`intellij-idea`、`orbstack`、`typora`、`insomnia` 等。完整列表见仓库 [Brewfile](https://github.com/zhijunio/dotfiles/blob/main/Brewfile)。

`dotfiles/.zshenv` 配置了国内 Homebrew / pip 镜像与 `HOMEBREW_NO_AUTO_UPDATE=1`。

```bash
brew bundle check --file Brewfile --verbose
brew bundle install --file Brewfile --no-upgrade --verbose
```

## Shell

`~/.zshrc` 顺序：Oh My Zsh → direnv（若有）→ OrbStack → Starship → aliases/functions → **`mise activate zsh`**。进含 `mise.toml` 的目录会自动切换工具版本。

Ghostty 由 cask 安装；Starship 主题自行维护在 `~/.config/starship.toml`（dotfiles 未托管）。

## Git 与其它

- `dotfiles/.gitconfig` 使用 **delta** 作 pager；未安装时可 `brew install git-delta`。
- GitHub 凭据走 `gh auth git-credential`。
- Maven：`dotfiles/settings.xml` → `~/.m2/settings.xml`。

## 验证

```bash
mise ls --current
node -v && pnpm -v && java -version
brew bundle check --file ~/github/dotfiles/Brewfile --verbose
```

## 日常

| 场景 | 命令 |
| --- | --- |
| 新机器 / 大改 | `./bootstrap.sh` |
| 只补 Brew | `brew bundle install --file Brewfile --no-upgrade` |
| 改运行时 | 编辑 `dotfiles/mise/config.toml` → `mise install` |
